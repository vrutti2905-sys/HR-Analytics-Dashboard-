# HR-Analytics-Dashboard-
HR Analytics Dashboard built using Power BI to analyze employee attrition, active employees, age groups, education fields, and job satisfaction. Features interactive filters, KPI cards, and charts to identify workforce trends and support better HR decisions.

# HR Analytics Dashboard

## Project Overview
This project presents an HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, workforce demographics, education fields, and job satisfaction.

## Key Performance Indicators
- Overall Employees: 1,470
- Attrition: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Age: 37 years

## Dashboard Visualizations
- Department-wise Attrition
- Employee Count by Age Group and Gender
- Job Satisfaction Rating by Job Role
- Attrition by Education Field
- Attrition Rate by Gender Across Age Groups

## Filters
- Associate's Degree
- Bachelor's Degree
- Doctoral Degree
- High School
- Master's Degree

## Tools Used
- Microsoft Power BI

## Project Objective
The dashboard helps HR teams monitor workforce trends, compare employee groups, review job satisfaction, and identify areas for further investigation.

## Key Takeaway
This project demonstrates how Power BI can transform HR data into visual insights that support workforce analysis and informed decision-making.
